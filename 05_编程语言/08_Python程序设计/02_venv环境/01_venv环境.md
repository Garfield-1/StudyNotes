# venv环境

**venv（虚拟环境）** 是 Python 内置的一个工具，用于创建一个**独立的、隔离的 Python 运行环境**。

### 核心概念

可以把它理解为：在你的项目目录下复制了一份"小型 Python"，它有自己独立的：

* **pip** — 安装包不会影响系统全局
* **site-packages** — 安装的第三方库只在这个环境里可见
* **python 可执行文件** — 指向同一份 Python，但隔离了包路径

### 为什么需要它

| 问题                                 | venv 的解决方式                   |
| :----------------------------------- | :-------------------------------- |
| 项目 A 需要库 v1.0，项目 B 需要 v2.0 | 各自创建独立环境，互不干扰        |
| 全局安装包可能破坏系统工具           | venv 里的安装完全隔离，不影响系统 |
| 想干净地删除某个项目的所有依赖       | 直接删除 venv 文件夹即可          |

### 基本用法

```shell
# 1. 创建虚拟环境（在项目目录下）
python3 -m venv myenv

# 2. 激活（进入环境）
source myenv/bin/activate

# 3. 正常使用 pip，安装的包都在 myenv 里
pip install pyinstaller

# 4. 退出环境
deactivate
```

激活后，终端提示符前会出现 `(myenv)` 标识，表示当前在虚拟环境中。所有 `pip install` 的操作都被限制在这个环境内，**不会污染系统 Python**。
